# Study Lab
A private EdTech portal for six subjects, with student login, admin announcements, class links, PDF/notes upload, and a SQLite database.

## Run
1. Install Node.js 20+.
2. In this folder run: `npm install`
3. Run: `npm start`
4. Open `http://localhost:3000`

Default admin login: `admin` / `studylab2026` (change this before public deployment).

For production, set `SESSION_SECRET` and use HTTPS. The site is designed to be deployed to a Node-compatible host with persistent storage.
